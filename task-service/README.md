📝 **Task Service**

The Task Service is one of the core microservices in the Task Management System. It is responsible for handling all task-related operations such as creation, updating, and deletion of tasks, along with role-based access control.

**Features**
-----------
Create new tasks (Manager only)
View tasks assigned to a specific employee
Update tasks (Employee only)
View all tasks (Admin, Manager, Employee)
Role-based access control
JWT-based authentication integration

🛠️ **Tech Stack**
-----------------
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT (integrated with Auth Service)

🔐 **Authorization Logic**
--------------------------
**Manager**
Can create tasks
**Employee**
Can view their own tasks
Can update their tasks
**Admin / Manager / Employee**
Can view all tasks

All routes are protected using JWT token verification

**Core Responsibilities**
------------------------
Handle task creation and assignment
Allow employees to update task status/details
Fetch tasks based on user role and authorization
Maintain secure access using role-based middleware

**Inter-Service Communication**
------------------------------
While creating a task, the service calls User Service to check if the assigned user is a valid employee
It also calls Project Service to verify the project exists
Ensures:
Task is assigned only to valid employees
Manager can assign tasks only to their employees
Task is created only under valid projects
JWT token is forwarded to other services for secure communication

**Integration with Auth Service**
---------------------------------
Uses JWT tokens generated by Auth Service
Verifies token before allowing access to any route
Ensures secure communication between services

**How to Run**

Install dependencies:
npm install

Add environment variables (.env):
PORT=5001
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key

**Start the service:**
npm start
