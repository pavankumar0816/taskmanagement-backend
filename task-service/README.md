## 📝 Task Service

The **Task Service** is one of the core microservices in the **Task Management System**. It is responsible for handling all task-related operations such as creation, updating, and deletion of tasks, along with role-based access control.

## Features
- Create new tasks (Manager only)
- View tasks assigned to a specific employee
- Update tasks (Employee only)
- View all tasks (Admin, Manager, Employee)
- Role-based access control
- JWT-based authentication integration

## 🛠️ Tech Stack
**Backend**: Node.js, Express.js<br>
**Database**: MongoDB<br>
**Authentication**: JWT (integrated with Auth Service)<br>

## 🔐 Authorization Logic
**Manager** : Can create tasks<br>
**Employee**: Can view their own tasks, Can update their tasks <br>
**Admin / Manager / Employee**: Can view all tasks <br>

All routes are protected using JWT token verification

## Core Responsibilities
Handle task creation and assignment<br>
Allow employees to update task status/details<br>
Fetch tasks based on user role and authorization<br>
Maintain secure access using role-based middleware<br>

## Inter-Service Communication
While creating a task, the service calls User Service to check if the assigned user is a valid employee
It also calls Project Service to verify the project exists. It Ensures: <br>
Task is assigned only to valid employees<br>
Manager can assign tasks only to their employees<br>
Task is created only under valid projects<br>
JWT token is forwarded to other services for secure communication<br>

## Integration with Auth Service
Uses JWT tokens generated by Auth Service<br>
Verifies token before allowing access to any route<br>
Ensures secure communication between services<br>

## How to Run
Install dependencies:
npm install<br>

Add environment variables (.env):<br>
- PORT=5000
- MONGO_URI=your_mongodb_connection
- JWT_SECRET=your_secret_key<br>

**Start the service:**<br>
npm start
